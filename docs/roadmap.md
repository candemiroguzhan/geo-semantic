# Roadmap

These capabilities are intentionally not implemented in v0.1.

## v0.2 — Data Management
GeoPackage, GeoParquet, editable dataset metadata, attribute filters, larger-dataset streaming and caching.

## v0.3 — Spatial Search
Bounding-box filters, distance queries, spatial relationships, NetTopologySuite analysis and optional PostGIS integration.

## v0.4 — Hybrid Semantic-Spatial Search
Semantic retrieval combined with spatial filtering, query intent classification and result fusion.

## v0.5 — GeoAI Agent
Generative LLM integration, tool calling, spatial query planning, RAG, and evaluation of LangChain/LangGraph or suitable .NET alternatives.

## v0.6 — Geospatial Foundation Models
Raster embeddings, satellite image search, multimodal retrieval and a Python inference service when necessary.

## v1.0 — EarthLens Integration
Earth observation analysis, geographic object detection, semantic segmentation, AI-assisted change detection and a unified geospatial AI workspace.
